Cuts for budget: task descriptions are halved first, then the feature description, only while a halving still shortens the text; no number constant in `judgment` (SpecNumbersTest).

  The review judge writes only the comments of a chunk whose hash is not stored yet, and counts the others in `skipped_same_input` (a new item row of one comment changes only that comment's hash, so a chunk can be half judged); it makes no call when none is left. `JudgmentStore.writeAll` is one transaction over `write`. The fact quote of 200 characters is a local in `ReviewCommentJudge.factOf`, not a constant (SpecNumbersTest); it counts code points.
