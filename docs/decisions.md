| 39 | 18 Nov 2026 | "No dead code" means: code whose work was taken over by other code is removed in the same change. | 40 | 19 Nov 2026 | For this PoC a feature's `plan.md` is a short plan: tasks in order, files, the first failing test of each, the commit. No line-by-line code. | 42 | 19 Nov 2026 | Bot PRs and bot comments are stored like any other record. | 44 | 19 Nov 2026 | The job endpoint `POST /api/jobs/{name}/runs` answers only callers on the same machine (loopback). | 46 | 19 Nov 2026 | The readers of stored GitHub rows are built by F03, their first user, not by F02 | No code waits unused | F02 design 11 |
